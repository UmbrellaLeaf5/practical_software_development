# ДЗ 3: Список студентов

## Задание

> В программе на C++ необходимо хранить список студентов. Для студента требуется хранить имя, фамилию, номер студенческого билета, успеваемость по предмету №1, №2, №3 и так далее.
> В список надо иметь возможность добавлять студентов и удалять.
> Список надо иметь возможность сортировать по разным "полям".
> Каким образом эту структуру данных можно было бы реализовать?

## Реализация

Каждый студент представлен классом `Student`. Он хранит имя, фамилию, номер студенческого билета и средние оценки в `std::map<std::size_t, double>`. Ключ карты -- номер предмета, а значение -- средний балл по этому предмету.

Класс `Manager` хранит список студентов в `std::vector<Student>`. При добавлении он проверяет уникальность номера студенческого билета. Удаление выполняется по этому номеру. Для сортировки используется `std::ranges::sort`: список можно упорядочить по имени, фамилии, номеру билета или оценке за выбранный предмет. Перед сортировкой по оценке программа проверяет, что у всех студентов есть оценка по указанному предмету.

Ошибки передаются исключениями `std::invalid_argument`: например, при повторном номере билета, удалении отсутствующего студента или сортировке по несуществующей оценке. Основной цикл программы перехватывает исключения и выводит сообщение об ошибке.

Программа принимает команды:

```text
add <номер_билета> <фамилия> <имя> <номер_предмета> <средний_балл>...
remove <номер_билета>
list
sort first_name|last_name|ticket_number
sort grade <номер_предмета>
help
exit
```

Например, команда `add 123 Иванов Иван 1 4.5 2 5.0` добавляет студента с оценками за два предмета, а `sort grade 2` сортирует студентов по средней оценке за второй предмет.
