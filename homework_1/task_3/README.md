# ДЗ 3: Список студентов

## Задание

> В программе на C++ необходимо хранить список студентов. Для студента требуется хранить имя, фамилию, номер студенческого билета, успеваемость по предмету №1, №2, №3 и так далее.
> В список надо иметь возможность добавлять студентов и удалять.
> Список надо иметь возможность сортировать по разным "полям".
> Каким образом эту структуру данных можно было бы реализовать?

## Реализация

Каждый студент представлен классом `Student`. Он хранит имя, фамилию, номер студенческого билета и средние оценки в `std::map<std::size_t, double>`. Ключ карты - номер предмета, а значение - средний балл по этому предмету.

Класс `Manager` хранит студентов и предметы через `std::shared_ptr`, поэтому связи между ними остаются действительными при сортировке списка студентов. Каждый предмет представлен классом `Subject` и характеризуется только номером. `Subject` хранит `std::weak_ptr` на привязанных студентов, чтобы не владеть ими и не создавать циклических зависимостей.

При привязке студент получает среднюю оценку по номеру предмета, а предмет получает ссылку на студента. При удалении студента или предмета менеджер удаляет все соответствующие привязки. Для сортировки используется `std::ranges::sort`: список можно упорядочить по имени, фамилии, номеру билета или средней оценке за выбранный предмет.

Ошибки передаются исключениями `std::invalid_argument`: например, при повторном номере билета, удалении отсутствующего студента или сортировке по несуществующей оценке. Основной цикл программы перехватывает исключения и выводит сообщение об ошибке.

Программа принимает команды:

```text
add <номер_билета> <фамилия> <имя>
remove <номер_билета>
list
sort first_name|last_name|ticket_number
sort grade <номер_предмета>
add subject <номер_предмета>
remove subject <номер_предмета>
subjects
subject <номер_предмета>
attach <номер_билета> <номер_предмета> <средний_балл>
detach <номер_билета> <номер_предмета>
help
exit
```

Например, последовательность `add 123 Иванов Иван`, `add subject 2`, `attach 123 2 5.0` создаёт студента и второй предмет, а затем привязывает студента к предмету со средней оценкой `5.0`. Команда `sort grade 2` сортирует студентов по средней оценке за второй предмет.
