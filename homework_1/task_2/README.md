# ДЗ 2: Вызов функции

## Задание

> Написать на стандартном C++ программу, состоящую из функции void fun (), и функции int main ().
> Функция void fun () должна выводить в стандартный вывод строчку "fun () implementation", больше ничего не делать, и успешно возвращаться.
> Функция int main () должна вызывать fun (), и обеспечивать, чтобы стандартный вывод программы был "main () successfully called fun ()". В конце функция main () должна возвращать 0.

## Реализация

`fun()` всегда пишет свою строку в `std::cout`. В `main()` буфер `std::cout` на время вызова перенаправляется в `std::ostringstream`, поэтому вывод `fun()` сохраняется в памяти, но не попадает в стандартный вывод процесса. После восстановления исходного буфера `main()` выводит требуемую строку.

```text
main () successfully called fun ()
```
