# ДЗ 1: Неперехваченное исключение

## Задание

> Что происходит, если в C++ программе выброшен exception, и нигде не пойман?
> Можно ли таким exception вывести диагностику для пользователя?

## Ответ

Если исключение покидает `main()` или обработчик `noexcept`, не встретив подходящего обработчика `catch`, по умолчанию, программа завершается аварийно, выводя текст исключения.

Собственно, некоторую диагностику можно вывести как раз в тексте этого исключения, если же речь идёт про более подробное сообщение для пользователя, то исключение нужно поймать с помощью `catch`. В обработчике можно вывести понятное сообщение с описанием ошибки, а затем корректно завершить программу.
