# Практическая разработка программного обеспечения

## Краткое описание

Это репозиторий с моими домашними и семинарскими работами по курсу «Практическая разработка программного обеспечения», который читается в седьмом семестре на четвертом курсе кафедры Специальных Летательных Аппаратов и Авиационных Информационно-Измерительных Систем ПИШ ФАЛТ МФТИ.

## Окружение разработки

Для воспроизводимой сборки используется [pixi](https://pixi.sh). Конфигурация устанавливает компилятор `g++` с поддержкой C++23, CMake и Ninja.

```text
pixi run build
```

Команда создаст каталог `build`, сконфигурирует проект CMake в режиме отладки и соберет все цели.

Для расширения CMake Tools в VS Code доступен Kit `Pixi GCC` из файла `.cmake/cmake-kits.json`.
